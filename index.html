get the gpg key

sudo curl -fsSL soniceggman419-ship-it.github.io/linux-kernel7.3.0repo/public.key -o /etc/apt/keyrings/linux-kernel7.3.0repo.asc

Types: deb URIs: https://soniceggman419-ship-it.github.io/linux-kernel7.3.0repo/ Suites: stable Components: main Signed-By: /etc/apt/keyrings/linux-kernel7.3.0repo.asc
